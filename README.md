# Chat Bubbles (Fabric, Minecraft 26.2)

Клиентский мод: сообщения чата появляются облачками вокруг персонажа.

- `O` — меню настроек
- `K` — режим курсора: ЛКМ по облачку убирает его (выход: `K` или `Esc`)
- Облачко исчезает само через заданное время (по умолчанию 10 с)

Сборка: любой push запускает GitHub Actions, готовый jar лежит в артефакте `chatbubbles-jar`.
Нужны Fabric Loader 0.19.3+ и Fabric API для 26.2.
